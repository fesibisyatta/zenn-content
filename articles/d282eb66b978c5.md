### 説明変数および目的変数の設定
順位回帰は以下の指揮をもとに推定する.

$$
\operatorname{prayer}_i = \beta_{\operatorname{female}}\operatorname{female}_i + \beta_{\operatorname{vocab}}\operatorname{vocab}_i + \beta_{\operatorname{female.vocab}}\operatorname{female.vocab}_i
$$

説明変数および目的変数を以下で設定する. 本文では, 教科書に倣い, 切片はつけない.

```python
# 目的変数と説明変数
y = df["prayer"]
X = df[["female", "vocab", "female.vocab"]]
```

ギブスサンプリングのための, パラメータ設定を行う.

```python
seed =1
NSCAN = 25000

rng = np.random.default_rng(seed)

y = np.asarray(y)
X = np.asarray(X)
n, p = X.shape

iXX = np.linalg.inv(X.T @ X)
V = iXX * n / (n + 1)
cholV = np.linalg.cholesky(V)

ranks = np.unique(y, return_inverse=True)[1] + 1
uranks = np.unique(ranks)

# Initialization
order = np.lexsort((rng.random(n), y))
z = norm.ppf(np.argsort(order) / (n + 1) + 1 / (n + 1))

b = np.zeros(p)
BETA = np.full((NSCAN, p), np.nan)
Z = np.full((NSCAN, n), np.nan)

ac = 0
```

以下で, パラメータ $\beta$ と 潜在変数 $z$ をサンプリングする.
```python
for nscan in tqdm(range(NSCAN)):

    # Update beta
    E = V @ X.T @ z
    b = cholV @ rng.standard_normal(p) + E

    # Update z
    mu = X @ b

    for r in rng.permutation(uranks):
        ir = ranks == r
        lb = np.max(z[ranks < r], initial=-np.inf)
        ub = np.min(z[ranks > r], initial=np.inf)
        z[ir] = truncnorm.rvs(
            lb - mu[ir],
            ub - mu[ir],
            loc=mu[ir],
            scale=1,
            random_state=rng
            )

    # Help mixing
    zp = z + rng.normal(0, n ** (-1 / 3))

    lhr = np.sum(
        norm.logpdf(zp, loc=mu)
        - norm.logpdf(z, loc=mu)
    )

    if np.log(rng.uniform()) < lhr:
        z = zp
        ac += 1

    BETA[nscan, :] = b
    Z[nscan, :] = z

# 平均
beta_pm = BETA.mean(axis=0)
z_pm = Z.mean(axis=0)
```

### 事前分布と事後分布の比較
事前分布と事後分布は以下のコードで可視化する.
```python
n = X.shape[0]
prior_sd = np.sqrt(np.diag(np.linalg.inv(X.T @ X / n)))

fig, axes = plt.subplots(1, 3, figsize = (12, 4))

for j, ax in enumerate(axes):

    xmin = beta_pm[j] - 2 * beta_sd[j]
    xmax = beta_pm[j] + 2 * beta_sd[j]
    xmin = - prior_sd[j]
    xmax =   prior_sd[j]
    x = np.linspace(xmin, xmax, 200)

    # 事前分布
    ax.plot(x, norm.pdf(x, loc = 0, scale = prior_sd[j]), color = "gray", lw = 2, label = "Prior")

    # 事後分布
    kde = gaussian_kde(BETA[:, j])
    kde.set_bandwidth(bw_method = "silverman")
    ax.plot(x, kde(x), color = "blue", lw = 2, label = "Posterior")

    ax.set_xlim(xmin, xmax)
    ax.set_xlabel(f"$\\beta_{j}$")
    ax.set_ylabel("Density")
    ax.legend(frameon = False)
```

以下のようなグラフを得る. このグラフを見ると

* 女性であることは, 祈りの回数に対してポジティブな影響を与えている.
* 語彙スコアは負の影響を与えていそうだが, あまり強い結論は出しにくそう. 有効サンプルサイズの分析でも95%信用区間が0を含んでいる.
* 女性の語彙スコアの結果は, 祈りの回数に対してネガティブな影響を与えている. 男女で語彙スコアと祈りの回数の関係が異なることを示唆している.
